세 시안은 같은 내용(소개, 대표 프로젝트 12개, 최근 글, 경력, 기술, 활동 그래프)을 담고 있고, 레이아웃·타이포그래피·영한 병기 방식만 다릅니다. 오른쪽 미리보기는 GitHub 렌더링을 흉내 낸 화면입니다. 점선 상자는 GitHub Actions가 자동으로 채울 영역입니다.

세 시안 공통으로 바뀌는 데이터

  • 대표 프로젝트 교체: 최근 활동한 공개 저장소 11개로 바꿉니다. AI 에이전트 도구, 데스크톱 도구, 앱 세 묶음입니다.
  • 링크 정리: 비공개인 baby-calendar는 뺍니다. crewith, asset-management, projects는 실제 저장소 이름으로 고칩니다.
  • 배지 정리: 종료된 Hits 카운터와 동작하지 않는 &link= 파라미터를 없앱니다.
  • 추가: 위키(jaywapp-wiki.vercel.app) 링크를 넣고, 기술 목록에 Claude Code·Codex·MCP·Supabase·Python을 더합니다.

자동 갱신 (GitHub Actions)

  • 최근 글: 매일 티스토리 RSS를 읽어 README의 BLOG-POST-LIST 구간을 다시 씁니다.
  • 통계 카드: 외부 서비스 대신 워크플로가 직접 SVG를 만들어 output 브랜치에 올립니다. 외부 서비스가 멈춰도 깨지지 않습니다.
  • 기여 그래프 스네이크: 라이트·다크 두 벌을 같은 output 브랜치에 생성합니다.
