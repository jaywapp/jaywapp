# GitHub 프로필 전면 개편 — 설계

## 콘텐츠 순서

1. 큰 타이포그래피 중심의 이름·슬로건 배너
2. 짧은 한국어 자기소개와 영어 한 문장, 연락 링크
3. 기술 전문성
4. 경력
5. 프로젝트 이름·링크만 모은 짧은 목록
6. 마무리 슬로건

## 시각 언어

- 짙은 네이비, 따뜻한 흰색, 민트 강조색. 불필요한 이모지와 외부 배지 나열을 줄인다.
- 저장소가 직접 보유한 정적 SVG를 사용한다. 외부 폰트, 스크립트, 외부 이미지 임베딩, 가짜 통계와 제품 화면은 넣지 않는다.
- 이미지에 담긴 핵심 의미는 alt와 실제 Markdown 본문에도 제공한다. 600px 이하 화면에는 별도의 모바일 SVG를 `picture/source`로 제공한다.
- 단일 열 중심으로 구성하고 본문 표는 짧은 비교에만 사용한다.
- 프로젝트의 공개 상태(알파, 스토어 출시, 소스 비공개)를 실제 근거와 일치시킨다.
- KeyMan 이미지는 기존 공개 저장소의 가상 데이터 기반 UI 렌더링이며 실제 비밀값 저장 과정을 촬영한 증거로 표현하지 않는다.

## 유지보수와 보존

- 자산 위치: `docs/assets/profile/`.
- 이전 프로필: `docs/archive/profile-before-20261106.md`.
- 프로필 계정 설정 제안: `docs/profile-settings.md`.
- 프로필 README와 자산을 같은 커밋에서 게시해 깨진 중간 상태를 방지한다.
- 작업 브랜치를 사용하고 기준 HEAD가 변하면 다시 읽어 동시 변경을 보존한다.

## 검증

- README의 모든 상대 경로, 활성 링크, 비공개 repo URL 제거를 검사한다.
- SVG를 XML로 검사하고 PNG 렌더링으로 시각 확인한다.
- 게시 후 원격 파일의 본문과 SHA를 재조회한다.
- 공개 GitHub 프로필에서 이미지의 실제 로드 상태와 콘텐츠 순서를 확인한다.

## 후속 설계 — 2026-11-06

- 메인에서는 프로젝트별 제목·기능 설명·스크린샷·스택 태그·공개 상태 안내를 제거한다.
- `Projects` 섹션에는 공개된 저장소와 서비스의 이름·링크만 남긴다. 설명 없는 비공개 실험 항목은 제외한다.
- 기존 Hero와 소개·기술 표·경력은 유지한다. 제품 이미지 파일과 이전 버전은 이력 보존을 위해 삭제하지 않는다.
- 검증은 설명·제품 이미지 부재, Markdown 구조, 기존 내용 보존 및 canonical read-back으로 한정한다. 새 기능이나 새 이미지가 없는 문서 축소이므로 빌드·실행 테스트는 필요하지 않다.

## 현재 역할 중심 소개 — 2026-11-06

- 제목: `Software Engineer · Developer Productivity & Tooling`.
- 핵심 메시지: 게임 개발팀이 게임에 집중할 수 있도록 도구와 환경을 만든다.
- 본문은 사내 도구, 빌드·인프라, AI 업무 흐름, 업무 자동화의 네 범주로 실제 업무를 설명한다. 특정 프로젝트의 홍보 설명은 추가하지 않는다.
- 기술 배경은 짧은 문장으로 유지하고 현재 경력은 게임 개발팀 내 지원 도구·시스템·개발 환경 업무로 수정한다.
- Bio와 데스크톱·모바일 배너도 사내 도구·빌드 시스템·AI 자동화에 맞춘다. 슬로건·색상·레이아웃은 유지한다.
- 검증: 사용자 진술과 문구 대조, SVG XML·미리보기, 프로젝트 링크 구간 보존, 원격 원문 재조회 및 Bio 저장 확인.

## 타이포그래피 중심 개편 — 2026-11-06

- 시각 방향: 잉크 블랙·아이보리·애시드 라임, 큰 글자와 여백 중심의 편집 디자인. 기존 네이비 그라데이션·JP 모노그램·회로 장식은 새 hero에서 제거한다.
- 새 자산: `editorial-v1.svg`, `editorial-v1-mobile.svg`. 파일명을 새로 두어 이전 이미지 캐시를 피한다.
- 슬로건: `I build what builders need.` / 한국어 핵심: `만드는 사람을 위한 엔지니어.`
- 기본 화면은 hero → 짧은 소개 → 연락 링크 → 프로젝트 이름·링크로 줄인다. 확인된 경력과 구체적인 업무·기술은 `Engineering background` details에 유지한다.
- 모바일 전용 SVG·alt 제공, 외부 폰트·스크립트·통계 위젯 없이 GitHub에서 안정적으로 표시한다.
- 부모 Codex가 문구·문서·게시를, 별도 Codex 세션이 SVG만 담당한다. 통합 후 XML·미리보기·GitHub 실제 렌더링·원격 전체 본문을 확인한다.
